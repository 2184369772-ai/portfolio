  • 唤醒方式：D0 (A0) 引脚配置为 GPIO 感知（analogRead 检测 FSR 压力 > 阈值持续 3 秒）
  • 深度睡眠：nRF52840 System OFF 模式，功耗 < 1µA
  • 自动关机：BLE 连接断开后 5 分钟无操作，自动进入深度睡眠
  • 充电：通过 XIAO USB-C 接口，BQ25101 内置充电管理，无需额外电路
  • 优势：零厚度增加（不需要物理开关），极低待机功耗

USB-C 缺口：XIAO 的 USB-C 接口需要露出来，用于固件烧录和调试。 可以在 PCB 边缘开一个 U 型缺口。产品封装时用薄膜覆盖即可，需要烧录时揭开。

制作流程

步骤操作耗时
1下单 PCB — 嘉立创上传 Gerber，选 0.8mm 黑色 HASL3–5 天
2采购元件 — 同时下单 XIAO + FSR + 电池 + 薄膜3–5 天
3焊接 PCB — 先焊 10KΩ 电阻，再焊 XIAO 到 PCB 焊盘1–2 小时
4焊接 FSR — 用漆包线将并联 FSR 连到 PCB 的 D0/GND30 分钟
5焊接电池 — BAT+/BAT- 焊线连接锂电池15 分钟
6烧录固件 — USB-C 连电脑，Arduino IDE 上传固件（含深度睡眠+唤醒）5 分钟
7封装 — PET 薄膜 + 双面胶 包裹，FSR 面朝上30 分钟
8测试 — 长按 FSR 3 秒唤醒 → 连手机 App 蓝牙 → 测试节拍检测—
6

注意事项与风险

⚠️ XIAO 焊接难度：XIAO 是 SMD 元件，焊盘间距较小。建议用电烙铁 + 细焊丝（0.5mm）+ 助焊剂。 先在 PCB 焊盘上上锡，再把 XIAO 对准放上去，用烙铁逐个引脚熔合。如果有热风枪会更容易。
✅ 充电无需额外电路：XIAO 自带 USB-C 接口 + BQ25101 充电管理 IC，插线即可充电。 产品上只需预留 USB-C 接口露出位置。
✅ 深度睡眠零额外元件：唤醒方案通过固件实现，利用 nRF52840 的 System OFF 模式 + GPIO 中断， 不需要物理开关，不增加厚度，待机功耗 < 1µA。
ℹ️ 深度睡眠需要改固件：当前固件是持续运行模式，需要新增：
(1) System OFF 睡眠 API 调用；(2) 长按 3 秒唤醒逻辑；(3) 自动超时关机（5 分钟无连接）。
代码改动不大，但需要在 PCB 打样前测试确认 nRF52840 的 D0 引脚支持 GPIO 感知唤醒。
✅ App 无需修改：BLE 协议不变，App 直接连接使用。
