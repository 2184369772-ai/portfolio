项目背景 Project Background

原来的资产管理主要依赖纸质资产卡和 Excel 台账，查询不方便，状态更新分散，盘点过程麻烦，生命周期也难以持续追踪。

这个项目的重点不是做几个页面，而是把线下记录、资产状态和盘点动作整理成一个可维护、可查询、可留痕的小型系统流程。

技术取舍 Technical Decisions

一期优先快速落地和验证，所以采用了更轻量的组合：FastAPI、SQLite 和 Web UI。重点不是炫技术，而是先把资产主数据、查询、扫码盘点和导入导出这些核心流程跑通。

同时，数据结构也预留了后续扩展空间，比如多人使用、集中部署，以及在需要时迁移到 MySQL 等数据库，而不是把一期方案锁死成一次性原型。

项目复盘 Reflection

内部数字化系统的价值，不只是把 Excel 做成网页。真正重要的是，把现实中的资产、状态、盘点和人员操作，变成一套一致、可维护的系统流程。

这个项目也说明，哪怕是一期较轻量的方案，只要它能让查询、状态维护、扫码盘点和后续生命周期扩展更清晰，就已经比原来的纸质卡片和 Excel 流程前进了一步。
